# 双轮式智能导盲杖 iOS 演示

这是用于项目展示的原生 SwiftUI 应用，可在 iPhone 上离线回放五个软件测试场景。应用展示路线示意图、控制状态、模拟舵机角度和停步原因。

| 场景 | 可观察的行为 |
| --- | --- |
| 前方通畅 | 从待命进入直行，目标角度为 0°。 |
| 左侧可绕 | 左绕、通过障碍并恢复直行。 |
| 右侧可绕 | 右绕、通过障碍并恢复直行。 |
| 前方阻塞 | 提示停步，舵机控制输出关闭。 |
| 雷达超时 | 从直行切换为停步，显示超时原因。 |

界面使用原型软件测试的离散状态与时间戳。回放按固定间隔推进，便于讲解。路线是示意图，时间戳来自程序日志。应用不连接或控制实体导盲杖，演示结果不代表实物测试。

## 运行

需要 macOS 和 Xcode 16 或更新版本。项目的最低部署版本为 iOS 17，使用 SwiftUI 和系统自带组件，无需安装第三方依赖。

1. 下载并解压 iOS 源码包，或克隆本仓库。
2. 打开 `ios/GuideCaneDemo.xcodeproj`，选择 `GuideCaneDemo` 方案。
3. 选择 iPhone 模拟器，按 `⌘R` 运行。使用实体 iPhone 时，请在 **Signing & Capabilities** 选择自己的开发团队后运行。
4. 在应用里选择场景，可以自动播放、逐帧查看或重置。

在 Xcode 按 `⌘U` 可运行界面测试。测试覆盖左绕的逐帧切换、重置，以及前方阻塞后自动播放到停止并关闭舵机输出。
