# 机械结构与装配

使用两只带独立轴承的自由滚动轮。操作者提供推进力，转向舵机通过舵盘和球头连杆旋动下轮架。上层支架装雷达和 IMU，通过俯仰铰链和杖杆相连。轮架转向时，上层支架与雷达无需同步转动。用独立竖轴和轴承承受支架负荷，舵机只传递转向扭矩。

| 位置 | 建议起调值 | 装配验证 |
| --- | --- | --- |
| 车轮 | 直径 150 mm，宽 25～35 mm，轮心距 230～270 mm | 左右独立滚动，保留刹车压块和编码器安装面 |
| 转向轴 | 穿过两轮轴心之间的中点 | 带载自由转动，确认轴承可承受轴向力与侧向力 |
| 转向限位 | 固件初始 ±25° | 连杆先脱开并找中位，机械硬限位高于正常软件限位，低于干涉角度 |
| 扫描面 | 离地 200～250 mm，首设 225 mm | 各推行姿态测量扫描高度和前方遮挡 |
| 握把 | 离地约 850～1050 mm，可调 | 握把能保持使能并立即操作手刹，杆件与锁紧件无松动 |
| 手刹 | 刹把经均衡器牵引左右制动件 | 左、右极限和直行三个位置均可断电刹停，线管有足够活动余量 |

用 [OpenSCAD 布局](../hardware/layout.scad) 查看前向空间、轮距和转角之间的关系。优先根据实购车轮、轴承座、转向轴和刹车件画孔位，然后制作金属支架。模型给出布局外形，钻孔、承载和疲劳强度按实际配件核对。

1. 装轮和刹车架。架空底盘，分别转动两轮，按下和松开刹车检查两边是否同时动作、回弹和脱离。装上杖杆与俯仰铰链后，检查刹车线不随杆件摆角拉紧。
2. 安装转向轴和手动可转的下轮架，设置机械止挡。空载和带载分别在左右极限检查车轮、外壳、线束、刹车件及连杆间隙。
3. 脱开舵机连杆定位中位。重新接连杆后，用弹簧秤在已知力臂上测等效阻力，以力乘力臂估算转轴扭矩，再按连杆最不利角度核算舵机轴负荷。短时测启动和峰值电流，记录带载回中时间和温升。 [DS3218 数据手册](https://www.dsservo.com/d_file/DS3218%20datasheet.pdf)
4. 固定 AS5600 磁铁与传感器位置。磁铁随下轮架转动，传感器与上支架固定。参考 AS5600 的磁体约束和状态位检查距离、轴心偏差及偏摆。 [AS5600 数据手册](https://look.ams-osram.com/m/3ac60b27c91075b5/original/AS5600-FS000133-2-00.pdf)
5. 固定雷达及 IMU，调整扫描平面并记录与转向轴的偏移。装对应接口的保护和固定件，避免线束进入轮架或刹车运动范围。
