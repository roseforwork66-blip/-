# 标定和台架验收

准备可架空轮组的支架、万用表、限流台架电源、卷尺、角度尺、软质障碍物和可清空的室内平地。由一人推行、一人旁站观察。先测电气和手刹，再验证转向，最后用软质障碍测试移动避障。

## 1. 断电和传感器检查

1. 关闭舵机支路，保留 `enableSteering = false`。手动旋轮，在杖杆俯仰与转向整个行程内测试手刹、线束余量、硬限位和空行程。确认握把松开、断电开关动作、MCU 复位时联锁输出均变为断电状态。用万用表验证舵机连接器的供电状态。
2. 烧录程序，保持样机静止后上电，让陀螺仪采集零偏。确认日志的 `imu=ok` 和 `pwm=ok`，运行日志中 `ok` 为 `11111`。若上电标定失败，检查 I²C 线和地址，在完全静止状态重新上电。
3. 雷达先用原厂工具确认旋转及扫描。接 MCU 后检查 `pts` 稳定、`age` 周期更新、`bad` 无持续增加。将高过扫描面的纸板依次放正前、左、右，在原厂工具读取原始角度，配置 `lidarForwardDeg`、`lidarDirection` 和实际 `lidarOrigin`。固件坐标规定左为正。
4. 轮架朝正前时记录日志 `w` 斜杠前的 AS5600 原始角，填入 `wheelAngleCenterRaw`，向左转动时斜杠后的度数应增加。轮组悬空转动两轮，校对左右编码器 A/B 相位。沿实际行进方向推行一段实测距离，分别用左右轮原始计数差的绝对值除以该距离，填入左右 `CountsPerMeter`，用 `CountSign` 使前进里程为正。先在低速回拉验证会报告负速度。
5. 保持上层支架水平，从上方看向左缓转。配置 `gyroSign` 使输入控制器的角速度为正。`gz` 是零偏校正后的陀螺仪原始符号，需要乘 `gyroSign`。核对供电 `V` 与万用表，按实测电压更新 `batteryDividerRatio` 和低压门限。在台架限流电源上测门限附近的停步反应。

## 2. 舵机和转向标定

先将舵机与连杆脱开，通过 50 Hz 可调 PWM 发生器或舵机测试器，从约 1500 μs 找到舵盘中位。找到中位后断电，固定零位并空载安装连杆，记录轮架向左和向右移动小角度所需的脉宽，计算对应的 `PulseUsPerDeg` 以及 `servoSign`。根据实测留余量设置 `minPulseUs`、`maxPulseUs` 和 `steeringLimitDeg`。软件初始为 ±25°，机械硬限位由装配间隙决定。

架空底盘、确认按钮与断电联锁，接上舵机后再把 `enableSteering` 置为 `true` 并重新烧录。接电后松开再按下使能观察轮架是否回中，按需关电调整。用软障碍模拟左、右指令时，用 `cmd` 和 `w` 对照运动方向、命令速率和到位误差。出现卡滞、方向相反、突转或复位即关断舵机，排查后重测。保持按键上电时，必须先松开再允许重新使能。

## 3. 移动试验与验收

停步警戒距离 `stopM` 按轮轴中点计。用实际最高测试速度乘以从扫描到提示的最坏延迟及人员反应时间，再加手刹作用后的实测滚动距离、轮轴至前缘距离、测量余量。重新配置时取多次测量中最不利值。若某组试验要求更长的距离，应扩大场地、降低速度或加大阈值。上车前在 `board_config.h` 的 `controllerConfig()` 中调整参数，并确保直行探测距离大于停步警戒距离。

| 场景 | 通过条件 |
| --- | --- |
| 断电和松手 | 手刹在直行及左右极限均能停住两轮。使能物理触点松开，以及断电开关动作，均可切掉舵机供电。 |
| 低速直行 | 先以约 0.2 m/s 在封闭平地推行，记录最坏感知和制动力延迟，均在预设安全线前停住。 |
| 单障碍绕行 | 约 3 m 宽走廊，用穿过扫描平面的 0.4 m 宽泡沫箱。左右各至少 10 次，记录底盘和人的最小净距、指令与实角，确认恢复参考航向。 |
| 一侧或两侧封堵 | 单侧封堵时在另一侧确实可见且可通行时绕行，两侧封堵或证据不足时振动并由人制动。 |
| 故障 | 先在轮架架空时模拟拔雷达、断 I²C、阻止角度反馈跟随、松手、舵机掉电和整机断电。记录软件停步输出、物理失电、振动与手刹结果。 |
| 停步后恢复 | 阻塞或故障解除、样机静止后，先松开再按下。按下时如果仍无安全路径，应继续停步。 |

每次记录部件版本、固件提交号、速度、左右封堵情况、扫描高度、净距、停步距离和结果。将故障、误判与扫描盲区纳入记录，保留未通过案例。
